# 反模式与交付前自检

---

## 反模式（明确禁止的"假核查"）

| ❌ 别这样 | 为什么不行 | 该怎么做 |
|---|---|---|
| 在同一段上下文里"再检查一遍" | 没隔离 = 被自己的草稿锚定。CoVe 论文证明 factored 明显优于 joint | 开独立子任务，禁止带入初稿 |
| 让模型自报"已验证"就算数 | 自报状态不是证据 | 要可追溯的源或工具输出 |
| 靠调 temperature 治幻觉 | 实证研究（npj Digital Medicine）：影响很小 | 靠结构和流程，不靠参数 |
| 无限加长 prompt | 长 prompt 反而使错误 **+10%** | 拆短、拆步骤 |
| 迷信 CoT / 长推理 | 复杂任务上 CoT 可能使幻觉 **+12%**；推理模型长文本摘要幻觉率 >10% | 推理必须配验证，不能替代验证 |
| 检索到什么就用什么 | RAG 静默失败 → "有据可查的假货"，隐蔽性最强 | 过滤噪声 + 强制引用追踪 + 相关性阈值 |
| 只报准确率 | 单一指标掩盖弃权代价 | 同时看错误率 + 弃权率 |
| 把"我不知道"当失败 | 当前评测惩罚弃权，导致模型习惯硬猜 | 本地反向激励：弃权是正确行为 |
| 用完即弃的核查 | 下次照样犯 | 每个出错案例进回归集 |
| 用户夸你就当验证 | 那是感官数据 | 设计可判定的检查 |

## 交付前自检表

输出前逐条过。**有任何一条不过，不许交付。**

### 事实层

- [ ] 每条事实性声明都有来源？无源的已删除并留 `[]`？
- [ ] URL / DOI / 论文 / 实体 / API / 文件路径——**逐个真查过**？
- [ ] 数字（百分比、日期、金额、版本号）回溯到一手来源了？
- [ ] 二手来源的数字，有没有标 `hearsay` 并点名出处？
- [ ] 有没有把"我记得"当成事实写？

### 验证层

- [ ] 核查是在**独立子任务**里做的，没被初稿锚定？
- [ ] 升级 `confirmed` 前**主动找过反证**？
- [ ] `confirmed` 的声明有 **≥2 个独立一手源**？（博客引博客 = 1 个）
- [ ] 工具失败 / 检索为空的，记成 `unverified` 而不是默认通过？
- [ ] 低置信声明附了**反例解释**？

### 表达层

- [ ] 语气对齐置信度？有没有用确定语气说没把握的事？
- [ ] `assumed` / `hearsay` 的标签在正文里可见？
- [ ] 声明了样本量？（n=1 只能 `observed`）
- [ ] 声明了边界？（这条在哪不成立）
- [ ] 打了日期戳？老知识（>90 天）重验过？

### 执行层

- [ ] "已完成"的每一条都有可追溯证据？
- [ ] 贴的是**完整命令输出**，不是"应该过了"？
- [ ] 子 agent 的报告独立验证过，没有采信它的自述？

### 风险层

- [ ] 风险等级判对了吗（L0/L1/L2）？
- [ ] L2 场景强制检索 + 人工闸门走了吗？
- [ ] 需要人工复核的标了 `needs_human_review`？

## 度量（长期）

至少跟踪这 8 个指标，否则不知道有没有用：

| 指标 | 说明 |
|---|---|
| claim 级事实性 | 有源声明 / 总声明 |
| response 级事实性 | 无幻觉回答 / 总回答 |
| 检索失败 vs 生成失败 归因 | 分清楚是检索的锅还是生成的锅 |
| **弃权率 / 不确定性表达率** | 太低 = 在硬猜 |
| 滚雪球式幻觉率 | 一个错引发一串错 |
| 对未知的自知力 | 不知道的事有没有承认不知道 |
| 引用可解析率 | 硬核查通过率 |
| **执行声明未验证率** | 声称完成但未验证的比例 |

**回归集**：每次线上出错加一条。改 prompt / 改流程后跑回归，防止按下葫芦浮起瓢。

可选用公开集：HaluEval、RAGTruth、ANAH、Chinese SimpleQA、HalluQA、LegalHallu、MedHalt、ToolBeHonest（工具幻觉）、Collu-Bench（代码幻觉）。

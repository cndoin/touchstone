# 01 · 核心原理：幻觉为什么必然存在，以及我们能做什么

> 只用两篇论文建立世界观：OpenAI arXiv 2509.04664（为什么去不掉）、ICML 2026 arXiv 2605.01428（那该怎么办）。
> 所有方法都建立在这个世界观上；不理解它，流程就会被当成形式主义跳过。

---

## 1. 幻觉不是 bug，是统计必然（OpenAI, arXiv 2509.04664）

**核心论点：幻觉 = 二分类错误。**

把生成看作一个 "Is-It-Valid (IIV)" 分类器：如果模型无法区分 valid / invalid 字符串，生成时就必然出错。这不是训练数据脏不脏的问题——**即使训练数据完全无错**，预训练目标（拟合语言分布）本身也会导致错误。

对"任意事实"（如某人生日、某 API 的冷门参数），**错误答案的样本量是正确的数百倍**，模型只能猜。

### 为什么幻觉"持续存在"：epidemic of penalizing uncertainty

主流评测用 0-1 打分：

| 行为 | 得分 |
|---|---|
| 答对 | 1 |
| 答错 | 0 |
| 弃权（"我不知道"） | **0** |

于是**"猜"在期望收益上永远优于"说不知道"**。

思想实验：Model A 保守（不确定就弃权）、Model B 永远猜 → 在现行榜单上 **B 赢**。

### 对 Skill 的直接启示

> **必须在本地重建一套"反 0-1 打分"的激励。**

本套件的做法：
- 显式奖励弃权：说"不知道"记为正确行为，不算失败
- 每条声明必须带置信度标签，语气必须对齐置信度
- 度量表强制同时看 **错误率 + 弃权率**（只报准确率 = 掩盖问题）

## 2. 目标不是"消灭错误"，是"忠实不确定性"（ICML 2026, arXiv 2605.01428）

**重新定义：幻觉 = confident error（没资格确定，却以确定语气输出错误信息）。**

### 校准 ≠ 判别力（这是最容易被混为一谈的一对概念）

| 概念 | 含义 | 当前水平 |
|---|---|---|
| **校准 calibration** | 整体自信度 vs 整体正确率是否匹配 | 前沿模型还行 |
| **判别力 discrimination** | 能否在**单条**上区分"这题我对了 / 错了" | **AUROC 仅 0.70–0.85** |

模型"总体上大概知道自己对多少"，但**指不出具体哪一条错**。这就是为什么"不确定就闭嘴"代价高到不可用。

### 实用性税（Utility Tax）—— 关键测算

基线错误率 25%，要把错误率压到 5%：

| 判别力 AUROC | 需要丢弃的正确回答 |
|---|---|
| 0.71（当前典型水平） | **52%** |
| 0.85（接近文献天花板） | **28%** |
| 0.95（需达到才可忽略） | 目前无方法接近 |

**结论：纯靠拒答不可行。** 第三条路是——**说，但带上校准过的置信度**，并把置信度用于路由（直接答 / 去检索 / 去核查 / 交给人）。

### Agent 场景是核心战场

有了工具之后，Agent 要回答的是元认知问题：
- 我需不需要搜？
- 搜到的信不信？
- 跟我的内部知识冲突时听谁的？

> 没有元认知的 Agent = 没有仪表盘的飞行员。

这正是本套件的定位：**给 Agent 装仪表盘 + 闸门**，而不是试图换个"不幻觉的模型"。

### 三个未解难题（诚实标注，别假装解决了）

1. **自举悖论**：静态数据教不会动态的能力边界
2. **对齐破坏信号**：RLHF 把预训练本就存在的不确定性信号磨掉了（人类偏好确定语气）
3. **因果性评估**：怎么区分"真元认知"和"表演元认知"

→ 因此本套件**不信任模型自报的置信度**，只信任可追溯的源和工具输出。

## 3. 两类幻觉要分开治

| 维度 | 含义 | 典型表现 |
|---|---|---|
| **Factuality 事实性** | 输出是否符合真实世界 | 编造论文、编造 API、编造日期 |
| **Faithfulness 忠实性** | 输出是否符合给定上下文/源材料 | 摘要偏离原文、篡改文档原意、虚构引用 |

一句话可以**忠实但错误**（源材料本身错了），也可以**正确但不忠实**（碰巧答对但没依据）。

**治法不同**：
- 事实性 → 外部检索 + 硬核查
- 忠实性 → 对照原文 + NLI 蕴含判断

## 4. Agent 场景的五种幻觉（对 Skill 最重要）

| 类型 | 表现 | 危害 | 本套件的对策 |
|---|---|---|---|
| **知识幻觉** | 凭训练记忆回答私有/最新问题 | 误导判断 | Zero Context 强制检索 |
| **工具幻觉** | 调用不存在的工具/接口 | 执行链断裂 | 工具白名单 + 存在性硬核查 |
| **参数幻觉** | 工具选对但参数编造、类型错、越界 | 调用失败 / 脏数据 | Schema 强校验 + 官方文档核对 |
| **证据幻觉** | RAG 没检索到却硬标来源、篡改原文 | **隐蔽性最强** | 强制引用追踪 + 相关性阈值 |
| **行动幻觉** | 声称已执行但实际没执行 | **最高危，不可逆** | 执行声明同闸 + 完整工具输出留痕 |

分类与 arXiv 2412.04141 的 *selection hallucination / usage hallucination* 划分一致。

## 5. 本套件的四个杠杆（模型权重改不了，能改的只有这些）

模型权重改不了、解码器改不了。Skill 层能落地的**只有四个杠杆**：

1. **强制溯源** —— 每条声明必须有源，无源即删
2. **结构化隔离核查** —— 草稿 → 原子化 → 独立子任务逐条验证 → 修订
3. **允许并奖励"我不知道"** —— 显式逃逸通道 + 置信度分级 + 风险路由
4. **可执行闸门** —— 把"必须检查"变成脚本，失败即不放行（v2 新增）

**四个杠杆缺一个，整套流程的有效性就归零。** 尤其是第 2 条的"隔离"——CoVe 论文证明 factored 明显优于 joint，省掉隔离，核查就退化成"为自己辩护"。

## 6. 一条硬规则：数据可信度分档

凡是进入正式产出的数据，必须过这一档：

| 档位 | 处理 |
|---|---|
| **一手可核验**（arXiv 编号论文、*Nature* 论文、官方文档、GitHub README/license、工具实际输出） | 可直接引用，注明出处 |
| **二手转述**（综述/博客里的百分比、"据研究显示"） | **必须回溯一手**；回溯不到 → 标 `hearsay` 并点名出处，或标 `unknown` |
| **榜单快照**（FACTS、HHEM leaderboard、AA-Omniscience） | 注明版本号与日期；**跨版本不可比** |

> 例："RAG 降幻觉 30–70%" 这类二手数字，不同来源口径不一致，进入正式产出前必须回溯原始出处；查不到就标 `unknown`。

---

## 7. 度量：三个必看指标（否则不知道有没有用）

1. **错误率**（error rate）—— 说错了多少
2. **弃权率**（abstention rate）—— 太低 = 在硬猜
3. **无源声明率**（unsupported claim rate）—— 有多少条是裸奔的

> 只报准确率是自我欺骗：一个永远猜的模型，准确率看起来也可以很体面。
